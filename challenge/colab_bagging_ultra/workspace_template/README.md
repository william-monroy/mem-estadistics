# Workspace Template

Esta carpeta representa la estructura que el notebook crea dentro de Colab.

No necesitas subir esta carpeta a Colab para que funcione el notebook.

Su función es mostrarte con claridad qué directorios existirán dentro del workspace temporal:

```text
/content/challenge_bagging_ultra_workspace/
├── data/
├── output/
│   └── challenge_07_bagging_colab_ultra/
│       └── checkpoints/
├── submissions/
└── exports/
```
