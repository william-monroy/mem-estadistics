## Criterio de redaccion

Cada archivo esta dividido en tres partes:

1. contenido para presentacion  
   Texto que puede ir casi directo en la slide. Se mantiene breve y legible.

2. dialogo de explicacion  
   Guion oral por slide. No repite literalmente la slide; la desarrolla.

3. respaldo tecnico y material de apoyo  
   Incluye decisiones metodologicas, numeros exactos, referencias a codigo y artefactos del repo, y sugerencias visuales.

## Narrativa sugerida

Para una presentacion clara, la narrativa recomendada es:

1. contextualizar el problema y el objetivo
2. explicar el preprocesamiento y el cambio de representacion
3. justificar el modelo final y por que se eligio
4. mostrar resultados y responder si el modelo realmente sirve para detectar fallas
5. cerrar con conclusiones, limitaciones y trabajo futuro
6. dejar lista la parte de contribuciones y referencias
