## 4. Instrucciones de uso

1. Reemplazar los nombres entre corchetes.
2. Ajustar verbos si algun integrante lidero una fase concreta con mas peso.
3. Mantener una narrativa honesta: equilibrada, pero fiel al trabajo real del equipo.
4. Si el docente pide mas detalle, combinar la tabla con la version expandida.
