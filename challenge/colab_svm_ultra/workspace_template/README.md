# Workspace Template

Esta carpeta representa la estructura que el notebook crea dentro de Colab.

No necesitas subir esta carpeta a Colab.

Su función es mostrarte con claridad qué directorios existirán dentro del workspace temporal:

```text
├── data/
├── output/
│   └── challenge_06_svm_colab_ultra/
│       └── checkpoints/
├── submissions/
└── exports/
```
